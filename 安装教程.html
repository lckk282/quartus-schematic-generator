Quartus 原理图批量生成器
安装与使用教程

在网页上勾选元件、填数量和引脚名，一键生成 Quartus II 的 .bdf 原理图工程， 并直接在 Quartus 里打开。所有逻辑在本地运行，不连网、不上传任何文件。

它能做什么

把「摆元件、连引脚」变成点几下鼠标

Quartus II 的 Block Editor 里一个个拖元件很费时间，这个插件把这步自动化了。

元件库直接调用

内置 Quartus 自带库索引，7490、74LS、门电路等符号随搜随用，引脚坐标自动对齐栅格。

现成模板

模 24 / 模 60 / 模 100 计数器、分频器、数码管译码等常用电路，选模板即可生成完整工程。

流程图预览

生成前先看预览：元件编号、引脚方向、连线是否打结，确认无误再写文件，不覆盖旧工程。

装之前先确认

系统要求

95% 的电脑都满足，只是确认一下不会被卡住。

项目要求说明
操作系统Windows 7 / 10 / 11插件用 Win32 接口唤起 Quartus，仅支持 Windows。
Python必需 3.8 及以上安装时务必勾选 Add python.exe to PATH；插件零第三方依赖。
Quartus II必需 9.1 或更高用它的元件库生成符号；安装程序会自动探测路径。
浏览器Edge / Chrome插件界面就是本地网页，双击启动后自动打开。
网络不需要全部本地运行，断网也能用。
安装

三步装好，不用改环境变量

整个文件夹拷到任意位置都能用（建议放 D 盘，路径别太深）。

1

确认已安装 Python

按 Win + R，输入 cmd 回车，在黑窗口里执行：

python --version

看到 Python 3.x.x 就跳过这一步。若提示「不是内部或外部命令」，说明没装或没加 PATH：

到 python.org/downloads 下载安装包，第一页底部务必勾选 Add python.exe to PATH，装完关掉所有命令行窗口，重新打开再试。
2

双击「安装.bat」

安装程序会自动完成 6 件事：检查 Python → 校验插件文件 → 找到 Quartus → 写入配置 → 建桌面快捷方式 → 装好「Quartus 一打开就自动弹出插件」并试启动。

如果它没找到 Quartus，会提示你把 …\quartus\bin64\quartus.exe 的完整路径粘进去，粘完回车即可。

只想体检、不想改动系统？在命令行运行 安装.bat --check，它只读不写。
3

双击桌面快捷方式开始用

首次会自动启动本地服务并打开浏览器，地址是 http://127.0.0.1:8765/。

页面顶部有一个环境状态徽标：绿色表示 Quartus 路径、器件库、输出目录都正常； 红色点开可以看到具体哪一项不对。

装完之后有两种用法，效果一样：
① 直接打开 Quartus —— 插件会自己弹出来（安装时已配好）；
② 双击桌面 Quartus原理图生成器，或文件夹里的 启动插件.bat。 插件已在运行时不会重复开服务，只会打开页面。
使用

生成第一张原理图

从「模板」或「元件清单」两种方式任选其一。

方式 A · 用模板（最快）

左侧选模板（如「模 24 计数器」）→ 右侧确认引脚名 → 点「生成」→ Quartus 自动打开 .bdf 与工程文件。

方式 B · 自己搭

搜索框输 7490 加进清单，填数量与引脚名 → 先「预览」看排版 → 没问题再「生成」。

生成的工程默认放在「文档\QuartusBatch」，文件名即实体名（只能用英文、数字、下划线）。 想换位置：改 app\config.json 里的 output_dir。
文件说明

文件夹里都是什么

只需要记住三个：安装.bat、启动插件.bat、app\config.json。

插件全部\
├─ 安装.bat              ← 双击安装（自动探测 Quartus、建快捷方式）
├─ 启动插件.bat          ← 日常启动入口
├─ 安装教程.html        ← 就是本页，可离线打开
├─ 卸载.bat              ← 清理快捷方式与开机启动
├─ install.py / launcher.py / uninstall.py
├─ README.txt            ← 纯文本速查
└─ app\                  ← 插件本体（别单独移动里面的文件）
   ├─ server.py          ← 本地网页服务
   ├─ config.json        ← 安装时生成：Quartus 路径 / 端口 / 输出目录
   ├─ symbols.json       ← Quartus 元件库索引
   ├─ templates.py       ← 内置电路模板
   └─ static\index.html  ← 网页界面
常见问题

装不上 / 用不了，先看这里

按出现频率排序，点标题展开。

双击后黑窗口一闪就没了，网页没打开

说明启动失败。用命令行看真实报错：

  • 在文件夹地址栏输入 cmd 回车，执行 python launcher.py；
  • 或直接执行 python app\server.py，报错会停在窗口里；
  • 也可以打开 app\server.log 查看最近一次日志。
提示「python 不是内部或外部命令」

Python 没装，或安装时没勾 PATH。两种解法：

  • 重新运行 Python 安装包 → Modify → 勾选 Add Python to environment variables；
  • 或手动把 C:\Users\你的用户名\AppData\Local\Programs\Python\Python3xx\ 和其下的 Scripts 加进系统 PATH。
安装时没找到 Quartus

安装程序会在 C/D/E 盘的 altera*、intelFPGA* 目录里找。装在别处时：

  • 重跑安装，按提示粘贴 …\quartus\bin64\quartus.exe 完整路径；
  • 或直接改 app\config.json 的 quartus_exe 与 quartus_lib（后者是 Quartus 根目录下的 libraries）。

注意：即使没配 Quartus，生成 .bdf 文件的功能仍然可用，只是「生成后自动打开」失效。

环境徽标是红色 / 器件库显示 0 个符号

点徽标看具体项。通常是 quartus_lib 指向的 libraries 目录不对：

  • 确认该目录下能看到 others\、arithmetic\ 等子文件夹；
  • Quartus 9.1 的库在 C:\altera\91\quartus\libraries；较新版本注意区分 bin64 与 bin。
网页打不开，提示端口被占用

安装时若发现 8765 被占用，会自动换成 8766 起。手动改也行：改 app\config.json 里的 port，然后重启插件。

想查是谁占了端口：netstat -ano | findstr 8765，再用任务管理器按 PID 结束。

点「生成」后 Quartus 没弹出来 / 报窗口找不到

插件是「唤起已打开的 Quartus 窗口」来打开文件，而不是新开进程。请先手动启动一次 Quartus II， 再回网页点生成；如果 Quartus 弹了「是否重新加载」的对话框，点「是」。

首次运行 Quartus 若报「Can't connect to the Altera web site」，点确定即可，与插件无关。

打开 Quartus 时插件没自动弹出来

自动弹出靠的是「启动」文件夹里的一条监控项，正常安装会自动装好。没弹时可这样排查：

  • 确认装过：重跑一次 安装.bat（它是覆盖安装，不会重复添加）；
  • 看日志 app\watcher.log，正常会有「监控启动，等待 Quartus」「已弹出页面」两行；
  • 若之前把监控关了：双击 安装.bat 即可恢复；不需要自动弹出就用 安装.bat --no-autostart。
不想要自动弹出，只手动双击打开

两种办法任选：

  • 重装时加参数：安装.bat --no-autostart；
  • 已经装了想撤掉：运行 卸载.bat，它会移除「启动」里的监控项 （之后仍可双击「启动插件.bat」手动用）。
怎么彻底卸载

双击 卸载.bat：删桌面快捷方式、删开机启动项，可选删配置与日志。 已经生成的原理图工程在「文档\QuartusBatch」，不会被动。

想彻底清掉，直接把整个「插件全部」文件夹删除即可，插件不写注册表、不装服务。
